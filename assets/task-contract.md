# Task Contract

Use a short conversational contract for small tasks. Fill only applicable fields. Preserve the user's existing specification and project rules. Save this template only with permission or under project policy.

## Outcome

State desired observable behavior, relevant project, and explicit non-goals.

## Constraints and authorization

State allowed paths, tools, model/configuration, experiment budget, prohibited side effects, and review requirements.

## Baseline and acceptance

Record current evidence, workload or reproduction, success measure, and regression checks. Mark missing measurements as unknown.

## Execution and evidence

Record hypothesis or change, actual command/action, input, tested revision and environment, observed output, and evidence location.

## Result and handoff

State verified outcome, failed or unrun checks, remaining risk, needed approval, and next concrete action. Include a real commit link only if one exists. Exclude secrets and sensitive raw logs.
